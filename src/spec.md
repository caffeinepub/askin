# Specification

## Summary
**Goal:** Add user name capture during role setup and implement a doubt Q&A system where Junior users can post doubts and Senior users can answer them.

**Planned changes:**
- Capture and store user names during role setup after login for both Junior and Senior users
- Enable Junior users to post doubts with description and optional image attachments
- Enable Senior users to answer doubts with text explanations and optional notes/video attachments
- Display user names throughout the UI (doubt cards, answer cards, header, leaderboard)

**User-visible outcome:** After login, users enter their names during role setup. Junior users can post doubts with optional images. Senior users can view doubts and provide answers with optional notes and videos. User names are displayed on all doubts, answers, and in the UI.
